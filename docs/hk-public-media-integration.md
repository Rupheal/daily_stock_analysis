修复分支专用，main 保留。富途行情 API 暂缓，允许15分钟行情延迟，分析仍使用完整交易日日线。

## 2026-09-12 接口实测

云端只读测试 run 34644529504：富途公开页返回公司新闻及 epoch 发布时间；新浪公司页返回文章链接；新浪搜索和财联社搜索只有动态网页框架；东方财富搜索返回错误栏目/无关公司，日线连接中断。这些失败不作为“无新闻”的证明，也不触发付费订阅。

新增公开新闻适配器读取富途结构化网页数据和新浪文章明确时间，沿用原生 DNS/SSRF/大小限制。新闻需通过公司关联、发布时间、三日时效和原文链接检查后入原生资讯池，并进入 DSA 上下文。保留媒体与获取渠道，不把富途转载财联社算成两个独立信源。只去重 URL 和标准化标题，跨语言、同事件不同标题仍可能重复。公告事实必须另核发行人或港交所；摘要、媒体报道、分析师观点均不能宣称原文事实已经全部核实。

港股日线顺序改为腾讯、Akshare（东方财富）、Yahoo及其他后备；不改变A股顺序。显式 end_date 请求若缺最新有效交易日日线，继续切换；未指定日期仍由下游完整日线门槛拦截。停牌缺日线不自动补造。

报告确定性复核接入 classic 和 Agent 港股分析保存历史之前；复核失败清除执行仪表盘并标记失败，阻断历史交易信号与正常通知。该检查覆盖已观察到的数值/语义错误，不等于所有自然语言事实都已验证，也不涵盖绕过 pipeline 的直接分析器调用。
