# 小米免费数据验收

在独立修复分支运行 `04-xiaomi-openbb-probe.yml`，OpenBB 使用隔离环境，DSA 依赖保持独立。脚本 `scripts/probe_xiaomi_sources.py` 保存行情、历史、新闻的原始响应及 UTC 采集时间。所有请求为读取；未配置模型密钥。单个 OpenBB 请求最多 90 秒，其他请求 20 秒超时。接口成功不代表数据验收通过，必须核对日期、复权、单位、实体关联和原文。结果存储在 Actions artifact，保留七天。

原版 main 不变；无定时任务。回滚可删除本工作流和探测脚本，不影响模型主流程。

此文为当前项目专用中文验收说明，无对应英文文档。
