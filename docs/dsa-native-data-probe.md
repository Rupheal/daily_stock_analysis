# 独立原生数据入口验收

`09-hk-native-data-probe.yml` 是手动/限定修复分支文件推送触发的数据测试，不是定时任务。

- U：修复分支当前提交、独立数据库、固定45只，全数保留覆盖分母。
- O：原生上游 `089d9d26d68f8b839ea5a74a3784e4402925f8b7`，独立检出与数据库；当前只验证小米数据入口。这个单股样本不是官方全池N，不产生原版TOP3。
- 两版调用自身 `main.py --dry-run --no-notify --no-market-review --force-run --workers 3`；不向原生逻辑注入研究因子。禁用自动回测；未提供模型凭据。
- 外围脚本核对代码提交和跟踪文件完整性，记录实际退出/超时、每只最新日线及缺失。当前完整交易日固定为2026-09-11；原生拉取成功与两源价格校验是不同门槛。
- 超时会终止本次原生进程组，保存数据库与日志。失败股票继续计入45，禁止据此缩小候选池。

复现：先安装原生依赖，再执行 `python scripts/run_hk_native_data_probe.py --help`；传入隔离检出目录、冻结池文件、确切代码提交和完整交易日。输出目录必须未存在，避免覆盖旧运行。

本中文文档专用于本研究分支验收，没有对应英文用户文档；本次不扩大至Web、Agent或通知入口。回滚只停用新增手动测试入口，固定事实V1及原生main均不受影响。
