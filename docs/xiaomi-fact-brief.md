# 小米固定事实简报 V1

本入口复用已有的腾讯/Yahoo日线核对、境外公司新闻和公告目录采集；无需模型即可生成中文HTML、Markdown及可复算JSON。它解决旧报告多处自由描述同一技术事实而出现矛盾的问题。固定事实简报可单独交付；原始模型交易方案仍未批准，策略有效性仍未验证。

## 使用

在修复分支的仓库根目录、已安装 requirements.txt 的环境运行：

```bash
python scripts/run_xiaomi_fact_brief.py --refresh --output-dir reports/xiaomi-facts
```

输出保存在带UTC时间的独立运行目录，打开 `xiaomi-facts.html` 即可阅读。每次重新抓取最新完整港股交易日；至少60个共同交易日的OHLCV交叉核验通过后生成。无需DeepSeek密钥。`.github/workflows/07-hk-news-integration.yml` 同样提供云端免费来源验收与报告artifact，并在运行摘要显示Markdown。不会打开收费工作流、TOP3或定时任务。

复看已有预检JSON时使用：

```bash
python scripts/run_xiaomi_fact_brief.py --preflight path/to/preflight.json --output-dir reports/xiaomi-facts
```

此模式明确标为快照回放，不重抓数据，不将历史快照称为最新。它核对快照中的价格约束，不等于独立重验所有远端原件。manifest保存本次文件SHA256；文件完整性不等于信源真实性证明。

## 发布范围

- 均线逐条列出前值、现值、变化与收盘相对位置；同日排列另列。K线只展示开收关系、实体、上下影、高低差及明确公式。
- 复用预检的日线计算函数；模型原文、预测概率、信号权重、基本面方向及执行建议不属于此产品的数据结构。
- 新闻只展示有日期和原媒体的标题索引与原链接；长摘要不复制进简报。跨语言去重仍有限，候选事件数不等于独立确认数。
- 未解决风险保留最初公开时间和最近复核时间。生成新报告不会把旧人工核查时间自动刷新。公告目录不冒充全部正文核验。
- 此入口的行情错误直接写failure.json并返回非零；不会生成本次可发布报告。新闻/公告不可用时可以生成覆盖受限的事实简报，明确展示缺失原因。既有模型预检默认继续严格要求新闻和公告，本次没有放宽模型门槛。
- 每次生成独立目录，旧报告不会被伪装成本次失败后的新产物。未集成到旧Web/Agent/通知的模型报告入口；用户应采用上面的明确入口。

## 验证与边界

本地覆盖5份历史失败模型输出无法进入新产品、涨跌幅与阴阳线区别、混合/同向/持平均线、零振幅、缺失与非法价格、失败出口、新闻隔离及离线无网络运行。云端补同一批相关回归、真实价格/新闻和最终HTML/Markdown/JSON生成；实际运行号见最新 `xiaomi-acceptance-checkpoint.json` 与 `dsa-project-progress.md`。

本版属于“数据与事实简报产品可用”，不等于完整DSA模型、财务研究、仓位止损或交易策略验收通过。它不推断股票未来收益。费用只报告实际模型请求数0；GitHub实际运行费用不能核实。
