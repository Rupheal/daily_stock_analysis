# 港股新闻网络出口与代理对照

2026-09-12 更新：用户选择用香港、美国、欧洲媒体替换默认大陆新闻来源。参见 [区域新闻源方案](hk-regional-news-sources.md)；当前不再把VPN/代理对照作为新闻模块运行的前置条件。下文保留为历史排障记录。

## 结论与证据

境外出口是待检验因素，尚未证明是主因。现有数据由 GitHub Actions 上的 DSA 请求，不能把 ChatGPT 客户端 IP 与运行器 IP 混为一谈。

| 来源 | 已观察到的结果 | 代理能否解决 |
| --- | --- | --- |
| 新浪 | 同一境外运行器在编码修复后取到6篇文章；搜索页为动态框架 | 网络部分可以对照；编码、动态加载不能靠换IP保证修复 |
| 财联社 | 搜索页HTTP200但没有静态搜索结果；富途转载可取 | 需核验动态接口；尚无境内/境外对照 |
| 东方财富新闻 | HTTP200但返回其他栏目与无关公司 | 可能涉及接口、参数、缓存或访问策略，根因未证实 |
| 东方财富日线 | RemoteDisconnected | 可能与线路、出口或服务端连接策略有关，适合做出口对照 |

证据：run 34644529504、34645447181。未记录分来源可靠延迟分布，不能以这两次结果推导普遍速度或境内优势。

## 可执行的测试

在现有 `scripts/probe_hk_media.py` 增加网络标签、最多3轮低频测试、响应头耗时、总耗时、解压后的响应字节数、明确错误类型。探测固定公开目标，无模型调用。标签是操作者填写的，不能冒充已验证出口地理位置。固定历史小米查询区间用于可比性，不是最新行情验收。

当前运行环境基线：

```bash
python scripts/probe_hk_media.py --network-label current-runner --repeats 3
```

在同一版本、同一时间窗口下，以受信HTTPS代理做对照。由操作者在运行环境/Secrets中设置 `DSA_NEWS_PROBE_PROXY`，不要把账号密码提交到仓库或作为命令行参数：

```bash
python scripts/probe_hk_media.py --network-label candidate-proxy --proxy-env DSA_NEWS_PROBE_PROXY --repeats 3
```

每次结果在 `probe/media/`；两次结果需分别保留，脚本会覆盖同目录 results.json。没有指定代理时使用运行环境原有网络设置，不能把它无条件称为“直连”。指定代理失败会明确记录，不悄悄走原出口。

比较：连接错误比例、HTTP状态、耗时、返回结构、日期、相关且去重后的新闻数。字节量仅作诊断，广告HTML更多不代表新闻更多。第一轮最多3次仅用于排查，不能估计可靠的p95延迟或长期稳定性。确认线路有改善后，再用原有公开新闻接入验收脚本验证内容。正式接入保留TLS、域名/DNS/私有地址限制，不采用不可信随机代理、TLS关闭或遇验证码持续换IP。

## 部署选择

建议先测试现有受信香港或内地出口，不预设地理位置就是胜出条件。如果需要单独节点，采用仅抓公开白名单媒体的轻量采集服务，模型调用保留原环境，返回带源URL、发布时间、抓取时间的结构化数据。一次抓取可缓存供两个模型复用，两个模型的股票池与策略仍各自独立。

当前原生资讯服务的 `_get_with_validated_dns` 显式禁用通用环境代理。此次仅扩展诊断脚本，没有关闭该保护，也没有把代理接入生产采集链路。正式使用代理需要在目标节点保留目的地址检查，或使用限定来源的采集服务；简单设置全局 HTTPS_PROXY 无法证明接入安全或已生效。

未创建服务器、未购买代理、未产生新增模型调用。当前没有已核实可用的候选出口，代理侧在线对照尚未执行，费用也未核实。完成这一步需要用户已有服务器/受信代理，或先提供具体新购方案与费用后再审批。
